# Modding Showcase

## Live Website

[Live Site](https://voltrex-dev.github.io/Modding-Showcase/)

## About the Project

This is my personal modding showcase. Modding has been one of my biggest interests for a long time, so I wanted to create a website where I could share some of the projects and mods I have worked on.

## Purpose

The main goals of this website are to:

- Showcase my modding projects and experiments.
- Practice and improve my web development skills.
- Create a central place for information about the mods I have worked on.
- Continue improving the site as I learn new techniques and technologies.

## Technologies Used

- HTML
- CSS
- CSS Grid
- JavaScript
- Git
- GitHub

## Future Improvements

I plan to continue expanding the website as I learn more. Some future improvements may include:

- More detailed pages for individual mods.
- Interactive JavaScript features.
- Showing which mods are currently working or in development.
- Improved page layouts and navigation.
- Screenshots and other media for my projects.
- Additional information about how each mod was created.

## About Me

Modding is something I am passionate about, and this project gives me the opportunity to connect that passion with what I am learning in web development. My goal is for this website to grow alongside my skills and become a better showcase of my work over time.
